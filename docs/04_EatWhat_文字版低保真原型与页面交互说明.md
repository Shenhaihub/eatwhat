# 2. 全局布局原则

## 2.1 响应式网页

EatWhat 只维护一套页面和业务代码：

```text
手机：单列、底部导航、一次突出一个任务
电脑：多列、顶部导航、可同时展示更多摘要
```

建议断点：

- 手机：小于 768px；
- 平板：768px–1023px；
- 电脑：1024px 及以上。

## 2.2 页面优先级

首页内容优先级：

1. 开始我的推荐；
2. 今日活动；
3. 今天大家都在吃什么；
4. 我的历史与设置。

## 2.3 公共数据冷启动

- 真实数据优先；
- 真实记录达到 3 条后才显示人数；
- 数据不足时使用默认热门项补足；
- 默认热门项不显示“演示数据”等标签；
- 默认热门项不显示虚构人数。

# 16. 免责声明页

1. 食物推荐；
2. 忌口与过敏；
3. 商家信息；
4. 品牌活动；
5. AI 推荐；
