## 3. 彩排中发现并处理的问题

### DRY-001 原型控制台会污染参与者判断

- 严重度：测试方法 S1，非产品 S1；
- 问题：测试者若看到登录、AI 速度、POI 状态等控制项，会提前知道系统结构并可能主动绕过自然判断；
- 修复：增加 `mode=participant`，从视觉和可访问树中隐藏控制台；
- 复验：320px 和 1280px 均隐藏，产品主路径不变；
- 后续影响：所有正式参与者必须使用带 `mode=participant` 的链接。

### DRY-002 自动化键盘证据仍不可靠

- 严重度：待人工验证；
- 现象：Playwright `press("Tab")` 无法派发；低层按键派发后焦点仍停留在程序聚焦的 H1；
- 判断：这是当前自动化通道的已知限制，不能当成产品键盘失败，也不能当成通过；
- 处理：T7 保持阻断性人工任务，至少一名参与者只用键盘完成主路径。

## 4. 不能由内部彩排回答的问题

以下内容必须来自 3–5 名真实参与者：

- 首页文案是否真的让人理解三路分流；
- 六个预设回答和最多三个 AI 追问是否感觉过长；
- 推荐理由是否让用户感觉结果来自自己的回答；
- “更多推荐”是否减少选择困难；
- 用户是否自然理解预算不保证商家价格；
- 真实犹豫、完成时间、退出步骤和主持干预；
- 真人纯键盘操作是否顺畅。

因此本记录不能作为 P0-06 完成证据。
