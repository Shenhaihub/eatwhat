## 四、必须长期保持的产品理解（权威基线）

以下来自 PRD v1.2 / 名词表 v1.0 / 预算契约 v1.0 / 收敛清单 G-01~G-16，**除非用户明确改变，否则视为稳定**：

1. **首页三路分流**：① 社区明确食物 → 直接附近商家；② 活动明确目标 → 直接附近商家；③ 开始推荐 → 混合自适应问卷。前两条不调用 AI、不消耗额度。
2. **混合自适应问卷**：2–3 个基础预设题 + 后端规则决策引擎选 2–3 个自适应题，覆盖七个信息维度（时段/食量/忌口/口味/预算/距离/明确食物倾向）；不调用 AI；不要求七页。
3. **决策引擎**：版本化问题库 + 条件表 + 确定性决策图；公开无 AI 接口 `POST /api/v1/questionnaire/next`；同版本同答案同路径；修改早期答案返回 `invalidated_answer_ids`。
4. **登录边界**：未登录可用所有非 AI 功能（含预设问卷、地点、POI，POI 受访客限流）；**仅即将调用 AI 时要求登录**，登录后恢复完整问卷，不得导致重填。
5. **AI 机制**：逐题追问，一次 1 题，最多 3 轮，信息充分可提前结束（服务端拥有最终停止权）；一次推荐最多 3 次追问调用 + 1 次最终生成调用；最终**固定生成 5 个食物候选**，前端按 **1→3→5 渐进展示**，展开不重新调用 AI。
6. **AI 边界**：只推荐食物类型（food_code），不选择、不编造、不断言具体商家/价格/营业/位置；商家事实只来自 POI Provider。
7. **推荐差异化（G-12，2026-08-03 用户实测发现）**：不同答案组合必须产生差异化的候选/排序，且理由可追溯到具体答案；不允许所有组合恒返回同一固定首候选。
8. **预算**：三档 `<20 / 20–30 / >30`，只影响食物方向（软偏好）；首版无可靠价格时不展示商家价格、不按预算筛选、不生成"符合预算/预算匹配"标签；AI 不得补全未知价格；未来参考价需来源+更新时间+可信状态。
9. **来源派生（G-07）**：`source_type` 只允许 `ai_recommended / user_selected / community_selected / activity_selected`，由服务端按真实执行路径派生；客户端只传入口意图；`rule_fallback` 是生成模式不是来源。
10. **规则回退非空（G-08）**：AI 失败时规则必须返回非空候选（通常 5 个），禁止空 `recommendations`，不扣额度。
11. **匿名分享不可回链（G-09）**：`shared_choices` 不含 `source_user_id/source_session_id` 及任何回链字段；不含问卷答案/口味/忌口/预算/距离/位置/AI 对话/商家/邮箱；公共记录最多含日期/餐段/food_code/来源/可选粗粒度区域；账户侧用"已分享"标记防重复。
12. **状态机（G-13）**：`questionnaire_in_progress → awaiting_login → ai_follow_up_generating → ai_follow_up_ready → final_generating → succeeded → food_selected → merchants_shown → completed`，另有 `failed / cancelled`。
13. **配额（G-14）**：用户可见额度按"一次完整推荐会话"计，每日 3 次，北京时间 00:00 重置；最终 AI 成功才扣；内部另设模型调用预算（3+1）与尝试限流。
14. **社区/活动首版必做（G-15）**：个人使用阶段不展示群体人数；阈值用配置 `PUBLIC_MIN_SAMPLE_SIZE`（默认≥3）；默认建议不显示虚构人数。
15. **坐标与删除权（G-16）**：精确坐标只用于当前附近搜索，不入 URL/日志/历史/分享；WGS84→GCJ-02；面向陌生用户在线服务前必须补齐邮箱验证/重置密码/账户删除/历史删除。
16. **收尾可跳过**：主任务完成后的评价、短问卷、匿名分享全部自愿、独立同意、不阻塞。
