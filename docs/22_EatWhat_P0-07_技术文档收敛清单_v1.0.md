## 2. 权威工程契约速查（工程实现以此为准）

以下 16 条是 05–13 勘误后的统一契约，工程脚手架和垂直切片直接引用。

| # | 契约 | 关键参数 |
|---|---|---|
| G-01 | 推荐对象 | AI 只生成食物类型 `food_code`；不选择、不编造、不断言具体商家、价格、营业状态或位置。商家事实只来自 POI Provider。 |
| G-02 | 最终候选数量 | AI 最终**固定生成 5 个候选**（priority 1–5，food_code 唯一且均在启用词典内）；前端按 **1→3→5 渐进展示**，展开不重新调用 AI。 |
| G-03 | AI 追问 | **逐题生成**：每次只生成 1 个问题，用户回答后再生成下一题；**最多 3 轮**，信息充分可提前结束（`should_continue` 由服务端拥有最终停止权）。一次推荐最多 **3 次追问调用 + 1 次最终生成调用**。 |
| G-04 | 登录边界 | 未登录可用**所有非 AI 功能**（首页/社区/活动/直接找商家/预设问卷/地点/POI，POI 受访客限流）；**仅即将调用 AI 时要求登录**，登录后恢复完整问卷上下文，不得导致重填。 |
| G-05 | 问卷结构 | 混合自适应：**2–3 个基础预设题 + 后端规则选择 2–3 个自适应预设题**，覆盖七个信息维度；不调用 AI；不强求七个页面。 |
| G-06 | 问卷决策引擎 | 后端 Questionnaire Decision Engine：版本化问题库 + 条件表 + 确定性决策图/DAG；公开、无 AI、无额度接口 `POST /api/v1/questionnaire/next`（保留 `GET /api/v1/questionnaire?version=`）；相同版本+答案返回相同路径；修改早期答案返回 `invalidated_answer_ids`。 |
| G-07 | 来源派生 | `source_type` 只允许 `ai_recommended / user_selected / community_selected / activity_selected`，**由服务端按真实执行路径派生**；客户端只能传入口意图，不能提交或覆盖 source_type；`rule_fallback` 不是来源，是生成模式。 |
| G-08 | 规则回退 | 规则回退/AI 失败**必须返回非空候选**（至少 1 个，按 G-02 通常 5 个）；**禁止返回空 `recommendations`**；不扣 AI 推荐额度。 |
| G-09 | 匿名分享边界 | `shared_choices` **不含 `source_user_id`/`source_session_id`** 及任何可回链字段；不含问卷答案、口味、忌口、预算、距离、位置、AI 追问、商家、邮箱、自由文本。公共记录最多含：日期/统计时间窗、餐段、最终 `food_code`、来源、可选粗粒度城市/区县。账户侧用"本会话已分享"标记防重复。 |
| G-10 | 预算语义 | 单人档位固定 `under_20`（<20 元）、`from_20_to_30`（20–30 元，含边界）、`over_30`（>30 元）。预算**只影响食物方向（软偏好）**；无可靠价格数据时不展示商家价格、不按预算筛选、不生成"预算匹配/符合预算"标签；AI 不得补全未知价格。未来参考价必须同时具备来源、更新时间与可信状态，且仅标注"平台参考"。 |
| G-11 | 预算数据字段 | 食物词典用 `supported_budget_tiers`（档位代码数组）+ `budget_fit_source` + `budget_fit_updated_at` 表达食物预算适配；**不用数字区间 min/max 冒充价格**。预算软匹配依据不足时状态为 `uncertain`，不得硬写匹配。 |
| G-12 | 推荐差异化 | **不同合法答案组合必须产生差异化的候选或排序，且理由可追溯到具体答案**；不允许所有组合恒返回同一固定首候选（P0-06 关闭时转入）。规则引擎与 AI 最终生成均适用。 |
| G-13 | 推荐状态机 | 采用名词表 §9 业务状态：`questionnaire_in_progress → awaiting_login → ai_follow_up_generating → ai_follow_up_ready → final_generating → succeeded → food_selected → merchants_shown → completed`；另有 `failed / cancelled`；状态由服务端维护，前端不得直接指定。 |
| G-14 | 配额 | 用户可见额度按**一次完整推荐会话**计，每日 3 次，北京时间 00:00 重置；最终 AI 结果成功并通过校验后扣 1 次；规则降级/直接/社区/活动路径不扣。内部另设模型调用预算（最多 3 追问+1 最终）与尝试限流，防止反复创建/放弃会话消耗 API。 |
| G-15 | 社区/活动 | 首版必做；个人使用阶段**不展示群体人数**；真实人数阈值用配置 `PUBLIC_MIN_SAMPLE_SIZE`（默认值不得低于 3，公众部署建议 ≥10）；默认建议不显示虚构人数；社区/活动明确 `food_code` 直达附近商家，不调用 AI、不扣额度。 |
| G-16 | 坐标与删除权 | 精确坐标（WGS84→GCJ-02）只用于当前附近搜索，不写入 URL、普通日志、业务历史、公共分享；位置上下文短 TTL、绑定会话、不可篡改。账户删除等生命周期能力：个人使用阶段可分里程碑，面向陌生用户提供在线服务前必须补齐邮箱验证、重置密码、账户删除、历史删除与说明。 |
