## 4. 验收中发现并修复的问题

### QA-001：AI 页在 320px 被隐藏图例撑宽

- 现象：AI 页 `scrollWidth=337px`；其他页面为 320px。
- 原因：通用 `.question-form legend { width: 100% }` 的选择器优先级高于 `.sr-only`，导致只供读屏使用的图例仍占整行宽度，并因绝对定位向右溢出。
- 修复：增加 `.question-form legend.sr-only` 的 1×1px 约束，并增加样式资源版本以规避本地缓存。
- 复验：AI 页 `scrollWidth` 从 337px 降为 320px；八个关键页面全部无横向溢出。
- 后续影响：正式组件库需要为 visually-hidden 工具类设置不会被业务样式覆盖的级联层或高优先级约束。

## 5. 键盘与可访问结构检查

结构检查结果：

- 可执行入口均为原生 `button`、`input`、`select`、`summary` 或链接；
- 非语义可点击元素数量为 0；
- 可见交互控件的负 `tabindex` 数量为 0；
- 可见输入控件未关联标签的数量为 0；
- 每个关键页面只有一个可见 `h1`；
- AI 页面包含可见 live region；
- 代码中没有拦截 `keydown`、`keyup` 或 `keypress`；
- 焦点样式、错误聚焦目标和 reduced-motion 样式均存在。

限制：当前浏览器自动化环境可以定位和聚焦控件，但没有正确派发按钮的 `Tab/Enter` 原生激活事件，因此未把“自动化键盘整链回放”伪装成已通过。基于原生控件和无键盘拦截，结构验收通过；P0-06 必须让至少 1 名测试者仅用键盘实际完成主任务，作为人工补充证据。
