# ADR-003: 社区活动模块数据来源与维护责任

> 日期：2026-08-24
> 状态：已采纳
> 关联：P6-03

---

## 1. 背景

EatWhat 社区模块包含以下核心数据：
1. **Feed 流**（`/api/v1/community/feed`）：用户分享的餐食动态
2. **Trending 榜**（`/api/v1/community/trending`）：今日推荐 Top 榜
3. **Theme 投票**（`/api/v1/community/theme`）：本周主题投票活动

这些数据需要明确：
- 数据从哪里来？
- 谁负责维护？
- 更新频率是多少？
- 数据过期如何处理？

---

## 2. 各模块数据来源

### 2.1 Feed 流

| 数据项 | 来源 | 维护责任 | 更新频率 |
|--------|------|----------|----------|
| Feed 内容（MVP） | 预配置 Seed 数据（`_MOCK_FEED_SEED`） | 产品团队 | 每月评审一次 |
| Feed 内容（P3+） | 用户发布动态 | 用户 + 社区运营 | 实时 |
| 作者信息 | 预配置 Seed（`_MOCK_AUTHORS`） | 产品团队 | 与 Feed 同步 |
| 点赞数 | 内存记录（MVP）/ history 表（未来） | 系统自动 | 实时 |

**Seed 内容维护流程**：
1. 产品团队每月评审现有 Seed 内容
2. 删除过时内容（超过 30 天的季节性内容）
3. 补充新内容（当月热门菜系、季节性推荐）
4. 保持 Seed 内容在 10-20 条之间

### 2.2 Trending 榜

| 数据项 | 来源 | 维护责任 | 更新频率 |
|--------|------|----------|----------|
| 聚合数据 | `history` 表（真实）/ `_TRENDING_SEED`（Seed） | 系统自动 | 每次请求实时聚合 |
| 菜系映射 | `_FOOD_CODE_TO_CUISINE` 字典 | 研发团队 | 食物字典更新时同步 |
| 最小阈值 | `_MIN_REAL_COUNT_FOR_PURE_REAL = 5` | 产品团队 | 可根据数据量调整 |

**数据降级规则**：
- 真实数据 ≥ 5 条 → 使用纯真实数据
- 真实数据 1-4 条 → 混合 Seed 数据填充
- 真实数据 0 条 → 纯 Seed 数据，标记"示例数据"

### 2.3 Theme 投票

| 数据项 | 来源 | 维护责任 | 更新频率 |
|--------|------|----------|----------|
| 主题内容 | 预配置（`THEME_ID`、`THEME_TITLE`） | 产品团队 | 每周更新主题 |
| 投票数据 | 内存记录（MVP）/ DB（未来） | 系统自动 | 实时 |
| 预置票数 | Seed 数据（`seed_jp_*`、`seed_kr_*`） | 产品团队 | 主题创建时设置 |

**主题创建规范**：
1. 每周一创建新主题
2. 主题需包含明确的选择题（如"日料 vs 韩餐"）
3. 添加主题描述和奖励说明（如"打卡送 AI 额度"）
4. 预置 100-300 票的假数据，避免 0/0 尴尬

---

## 3. 数据治理规则

### 3.1 数据新鲜度

| 数据类型 | 过期时间 | 处理方式 |
|----------|----------|----------|
| Feed Seed 内容 | 30 天 | 每月批量更新 |
| Trending 聚合数据 | 实时（当日） | 次日自动重置 |
| Theme 投票 | 7 天（每周主题） | 每周日 23:59 截止 |

### 3.2 数据一致性

- **食物代码一致性**：Feed 和 Trending 使用的 `food_code` 必须在食物字典 `v1.0` 中存在
- **菜系标签一致性**：`cuisine_tag` 需与字典中的菜系分类保持一致
- **去重规则**：点赞、投票均为幂等操作，重复提交不累加

### 3.3 隐私保护

- Feed 流的作者 ID 是匿名化的（`u_001` 格式），不暴露真实用户 ID
- Trending 榜只展示聚合数据，不记录单个用户的推荐历史
- Theme 投票的用户 ID 仅用于去重，不对外展示

## 4. 未来演进

| 版本 | Feed 流 | Trending 榜 | Theme 投票 |
|------|---------|-------------|------------|
| **MVP（当前）** | Seed 数据 | Seed/混合/真实 三级降级 | 内存投票 |
| **P3** | 用户可发布动态 | 接入 POI 数据 | DB 持久化 |
| **P6+** | 社区运营审核 | 加权聚合（热度+时效） | 多主题并行 |

| Theme 主题 | ✅ 创建主题 | 🔧 实现 | 📊 监控投票 |
