# EatWhat P0 响应式交互原型

可以直接在浏览器中打开 `index.html`。若浏览器限制本地脚本，也可以在本目录运行：

```powershell
node serve.mjs
```

然后访问 `http://127.0.0.1:4173/`。无需安装依赖或启动业务后端。

原型用于验证：

- 首页社区、活动、推荐三路分流；
- 基础题与自适应预设题；
- AI 登录边界和答案恢复；
- 逐轮 AI 追问、等待、失败和幂等重试说明；
- 五候选按 1→3→5 展开；
- 定位拒绝、POI 零结果/错误；
- 快速评价、改进问卷、匿名分享三个独立可选支线；
- 320px 响应式布局和键盘操作。

预算档位为 20 元以下、20–30 元、30 元以上。预算只用于演示食物方向偏好；原型商家数据不按预算过滤，也不承诺实际消费。

页面右下角“原型控制台”可以切换登录态、AI 响应速度和 POI 响应状态。

P0-06 可用性测试应使用参与者模式，避免控制台提示干扰测试者：

```text
http://127.0.0.1:4173/?mode=participant&ai=fast&poi=ready
```

可用参数：

- `mode=participant`：隐藏原型控制台；
- `ai=slow|fast|error`：预设 AI 响应场景；
- `poi=ready|empty|error`：预设附近商家场景；
- `login=1`：从模拟已登录状态开始，默认不登录。

“重置原型”会保留当前链接中的测试参数。测试主持人使用无参数链接时仍可看到完整控制台。

这是流程原型，不调用真实 AI、登录或地图服务，也不是最终品牌视觉稿。
